# v33 看得清一天发生什么

## 先成交信息，再记账

新销售仍在实际交货时记入同一份交易流水，但不立刻弹出报表挡住成交事实。先显示小票：杯数、每杯售价、营业收入总额、实际收到现金、未收款及本次消耗的原料和包材成本。用户点“看清楚了，去记这一笔”后才揭晓首次报表或进入填表。

手动填账时，报表顶部保留本笔杯数、单价、总价和实收 / 尚欠摘要。关闭账本仍保留草稿，可回主页面看事实；没有因为再次打开小票而多记一笔。

v32 将这块摘要扩展到全部手动记账：采购、设备购入 / 出售、借款、还款和费用也显示关键数字。摘要固定在报表分页区上方，键盘弹起后仍显示，三张表使用同一笔实际交易的事实。

普通日的营业结果先展示在主页面，自动填写的报表按需打开。报表中的变动行和新行仍有首次动画。普通日可以直接收好当天账目进入明天，已经确定的自动金额不要求再逐格输入或强制逐张翻阅。

## 一天的营业时钟

开张教学与每周重大决策保留独立场景；普通日从开摊进入 `dailyTrading`。中央大字显示正式经营第几天、上午 / 中午 / 下午 / 傍晚及数字时间；原钟面同时前进，太阳沿早晚时间轴移动，背景渐变到傍晚。每周周日不营业，进入盘账场景；第三周周二至周四显示逐天停摊的暴雨故事，不启动营业时钟或收款动画。

一天约 8 秒（80 个有效前台计时帧），按故事分钟推进，不按离线墙钟补算。原有局种子和日期确定当天客流总量，开摊时只做计划，随后一般用 4–6 次交易呈现一整天，12 杯以上的旺日约 12% 使用 7–8 次；单次兼有一杯、两杯或多杯，接单现打、交茶收款，同时消耗存货、确认收入和成本。每批发生时杯数、钱盒与今日净利润更新，并出现制茶杯、硬币移动与短促零钱声；没有提前把全天钱塞进钱盒，也没有用假数字代替实际账目。杯子递出恢复约 0.6 秒，硬币落袋约 0.7 秒，三枚硬币错开 0.09 / 0.17 秒，通常能完整播完再迎接下一笔。冷清日可以零销量或只卖一杯。旧档已经生成的到客计划保留，不重排已开始的一天。

未来客人和未发生结果不列入时间轴。已经完成的批次进入当天记录；日常营业到晚上结束，卖完可售材料或用完产能则提前打烊。没有卖出的日子只有时钟前进，现金不会凭空增加。结束后停在当日结果，仍由玩家点击进入下一天。

可随时暂停或快进。快进使用同一到客计划、金额与交易时间，只缩短呈现；减少动画采用相同结果。打开菜单、报表等浮层时停止推进。离开页面时明确暂停并保存当前分钟和已完成批次，返回或刷新后点击继续，不补算后台营业、不补播过去的收款声。已卖出的杯子不会重卖，清算时只处理真实剩余材料与已发生债权债务。

## 学的是专业概念

主概念从 `learning.js` 的规范名词中选取，由 `lesson-topics.js` 对应到场景，不把动作或营销语当新术语：

| 场景 | 专业概念 | 呈现 |
| --- | --- | --- |
| 按团购价计算 | 毛利 | 已学过毛利，标为复习 |
| 偿还供应商旧账 | 应付账款 | 保留“偿还”作为题目动作，概念本身仍是应付账款 |
| 首次购货未付清 | 应付账款 | 首次学习时标新概念 |
| 借款方案 | 借款本金、利息 | 已知本金作复习，利息首次出现时单独标新概念 |
| 收不回已交货款 | 应收账款、坏账损失 | 复用应收账款，确认为坏账时介绍坏账损失 |

首次学习的概念集合在点击学习时留存快照。后续学了更多概念，不会把以前的学习记录重新改成另一种标签。选择题的业务情境、答案、首次作答和实际账目保留；没有把复习题从共同路线删除，也没有分出初学者与有基础两套模式。

## 声音

默认是硬币落进玻璃杯的真实录音，约 0.90 秒；原落罐录音保留为设置内对照。两段均为 CC0，原音频文件未再加工。主音量保持原值，E 庆祝声的单独播放增益降为原来的 55%，合成回退同步降低。来源与处理见 `audio/COINS_CLINKS.md`。

## 验证范围

`npm run test:trading` 验证分批交货前没有提前收钱、库存 / 利润 / 现金同步、计时正常结束与无客流、暂停 / 弹层 / 后台 / 刷新 / 过期回调、快进和减少动画结果一致、清算中止，以及先读小票再进入报表、表头保留小票数字、规范名词与复习标签。完整 `npm test` 继续覆盖四周、旧档、概率结果、三表、输入和设备 DOM 行为。

没有可用的 Sites 指定浏览器入口，DOM 夹具不证明手机真实几何布局、动画手感或音效主观听感。发布后仍需用手机微信与 iPad 实测这些部分。
